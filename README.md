#  Unicorn Startups Data Analysis & Visualization

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a dataset of unicorn startups to understand startup trends based on **valuation, industry, country, city, and year of joining the unicorn club**.

The project uses Python data analysis and visualization libraries to clean the dataset, perform exploratory analysis, and create interactive visualizations that help identify patterns in the global unicorn startup ecosystem.

---

## 🎯 Objectives

The main objectives of this project are:

* Analyze the distribution of unicorn startups across different industries.
* Explore the number of companies joining the unicorn club over the years.
* Compare unicorn startups across different countries.
* Identify cities with a high concentration of unicorn startups.
* Analyze startup valuations.
* Identify highly valued unicorn companies.
* Analyze Indian unicorn startups.
* Explore Indian fintech unicorns.
* Visualize country-level startup distribution using a choropleth map.

## 🧹 Data Preprocessing

The dataset was inspected for:

* Missing values
* Data types
* Dataset dimensions
* Column structure

The following preprocessing steps were performed:

* Renamed columns for easier analysis.
* Converted valuation values into numeric format.
* Extracted **year, month, and day** from the joining date.
* Converted extracted date components into numeric values.
* Prepared the dataset for visualization and analysis.

## 📊 Analysis Performed

### 1. Unicorn Startups by Industry

Analyzed the distribution of unicorn startups across different industry sectors using a pie chart.

### 2. Year-wise Unicorn Growth

Explored companies based on the year they joined the unicorn club.

### 3. Country-wise Analysis

Compared unicorn startups across countries and examined India's position in the dataset.

### 4. City-wise Analysis

Analyzed cities with a high number of unicorn startups and identified cities with high total startup valuation.

### 5. Valuation Analysis

Sorted companies based on their valuation to identify highly valued unicorn startups.

### 6. India-focused Analysis

Performed additional analysis on Indian unicorn startups, including:

* Indian unicorn companies
* Indian startup valuations
* Indian startup industries
* Indian unicorns by year
* Indian fintech unicorns

### 7. Country-level Visualization

Created an interactive choropleth map to visualize the distribution of unicorn startups across countries.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Unicorn-Startups-Data-Analysis.git
```

### 2. Navigate to the project

```bash
cd Unicorn-Startups-Data-Analysis
```

### 3. Install the required libraries

```bash
pip install pandas numpy scipy matplotlib seaborn plotly jupyter
```

### 4. Start Jupyter Notebook

```bash
jupyter notebook
```

### 5. Open the notebook

Open:

```text
Unicorn Startups Data Analysis and Visualization.ipynb
```

Make sure `Startups.csv` is available in the same directory as the notebook.
